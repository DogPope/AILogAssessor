# AI Agent Log Assessment Application
The purpose of this project is to leverage AI Agents to assess logs from a given application to assess problems, remedy or suggest appropriate action to fix them.

## How to install and run the program.
* Install the code from the repository: 
```bash
git clone https://github.com/DogPope/AILogAssessor.git
```

* Download and install Docker Desktop
